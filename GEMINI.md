# Regras de Desenvolvimento do Projeto MIST

## Rastreamento de Prompts e Modificações

> **REGRA GERAL:**
> Após qualquer prompt executado pelo usuário dentro do ecossistema do projeto MIST, registre o prompt de entrada e o resumo consolidado das saídas/modificações no diretório `prompts/`, sob o arquivo `<user_dayth>.md` (exemplo: `gabriel-T800_26th.md` para o dia 26 e usuário `gabriel-T800`).
> Caso seja a primeira execução na máquina ou haja mudança de desenvolvedor/dia, valide o identificador do usuário ativo.
